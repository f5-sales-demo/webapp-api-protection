The [showcase overview](../) introduces the protection demonstrations.
Read [architecture and applications](../overview/) to follow the request path and choose
an application. Then [prepare the showcase](../demo/) before opening a controlled window.

Each use-case article compares the same synthetic input across two configurations, attributes
the response to a security control and checks legitimate requests. Start with
[SQL injection and reflected cross-site scripting](../web-application-protection/injection-and-xss/)
or select an API control. Fresh matched evidence remains pending until the private lifecycle
state preflight passes; see [implementation status](../origin-traffic-remediation-tasks/).
