The **Web Application & API Protection (WAAP)** demonstration illustrates how to secure modern web applications and APIs against multi-vector threats using F5 Distributed Cloud and Terraform automation.

## Architecture

<Steps>

1. **Client traffic** enters the public VIP of the F5 Distributed Cloud HTTP load balancer.
2. **Layer 7 inspection** applies Web Application Firewall signatures and staged enforcement. Bot Defense and Client-Side Defense provide their respective detection and client telemetry.
3. **Origin pool** forwards traffic to backend microservices and API endpoints.

</Steps>
