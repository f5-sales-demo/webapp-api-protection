The Azure showcase places nine intentionally vulnerable applications behind F5 Distributed Cloud HTTP and HTTPS load balancers and drives the full shared traffic catalog from a second Azure VM. Terraform declares WAF and API controls; their live evidence is assessed separately.

The origin and traffic generator consume shared immutable installers. The origin manifest supplies published prefixes and replica/workflow assertions; the traffic catalog preserves all 164 scenarios across 22 suites. CSD runs are display-only with `csd_enabled=false`.
